## 🚀 How to View Locally

Simply open `index.html` in any web browser:
```powershell
Start-Process index.html
```
No package managers, compilers, or build steps required.

---

## 🌐 1-Click Free Deployment

### GitHub Pages:
1. Create a repository on GitHub.
2. Push `index.html`, `style.css`, and `script.js`.
3. In repository **Settings > Pages**, choose the `main` branch.
4. Your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`.
